Chunk Metadata Schema

Every chunk stored in ChromaDB persists chunk_id, doc_id, file_name, page_number, source_type (native/ocr), and visibility scope.

Access Isolation

Multi-tenant authorization is validated at the retrieval step so no unauthorized document text enters the LLM's reasoning context.

Fast-Path Inference

High-confidence direct retrieval paths bypass multi-round agent iterations for simple queries to minimize latency.

Self-Healing DB

Catches database lockups, missing SQLite migration tables, and schema drifts automatically without service restart.
